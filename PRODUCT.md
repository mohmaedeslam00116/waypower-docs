# Product

## Register

brand

## Users

Developers who already use an AI coding agent (Claude Code or compatible) and
suspect the bottleneck is no longer the model's coding ability but its working
method. They arrive from GitHub, skills.sh, or a shared link. Their context:
evaluating waypower in under five minutes, mid-workflow, skeptical of
agent-tooling hype. The job to be done: understand what waypower is, decide if
it is worth installing, copy the install command, then later return to look up
one specific skill.

## Product Purpose

The documentation and proof surface for the waypower skill pack (13
pressure-tested agent skills forming an idea-to-ship pipeline). The site exists
to convert a skeptical evaluator into an installer, then serve as a fast
reference for installed users. Success looks like: the install command gets
copied; every skill page answers "when does this fire and what do I get" in
under a minute.

## Brand Personality

Confident, precise, calm. Engineered authority — the certainty of an expert who
does not need to shout. Voice: direct second person, short sentences, claims
always paired with evidence (eval tables, real transcripts, real numbers).
Never breathless, never cute.

## Anti-references

- AI-hype landing pages: giant gradient blobs, floating 3D shapes, vague
  promises ("revolutionize", "supercharge", "10x"), zero evidence.
- Cluttered enterprise docs portals: three nested navbars, banner walls,
  everything competing for attention.
- Marketing pages that hide the install command below the fold.

## Design Principles

1. **Show, don't tell** — every capability claim pairs with a real artifact:
   eval numbers, a transcript excerpt, a before/after.
2. **The install command is sacred** — findable within one scroll from any
   landing position, copyable in one click.
3. **Answer-first pages** — every page leads with what it is, when it fires,
   and what the reader gets. Depth below, never above.
4. **Calm authority** — whitespace and typography do the work; color is spent
   sparingly and only where it earns its place.
5. **Practice what you preach** — the site itself is built with waypower
   skills, and it says so openly (the dogfooding story is content, not a
   footnote).

## Accessibility & Inclusion

WCAG 2.1 AA minimum. Full dark and light themes with equal contrast rigor.
Respect reduced-motion. Code blocks legible at 200% zoom. No information
carried by color alone.
