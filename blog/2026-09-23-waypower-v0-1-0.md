Your agent already knows how to code. The bottleneck was never the model's
syntax — it's that nobody taught it *how to work*: how to refuse a vague
brief, how to plan before building, how to prove a claim before making it.

waypower v0.1.0 is out today: **13 pressure-tested agent skills** forming one
idea-to-ship pipeline for Claude Code and compatible harnesses.

```bash
npx skills add mohmaedeslam00116/waypower --all -g --copy
```

{/* truncate */}

## What's in the pack

- **1 orchestrator** — `using-waypower`, always active, routes every task to
  the right process skill and disarms the rationalizations agents use to skip
  process.
- **8 process skills** — auto-invoked on their triggers: `design-interview`,
  `tracer-plan`, `seam-design`, `seam-driven-tdd`, `hypothesis-debugging`,
  `domain-glossary`, `completion-gate`, `dual-axis-review`.
- **4 tool skills** — invoked by name when you want them: `waymap`,
  `finish-handoff`, `deep-research`, `authoring-skills`.

## Why "pressure-tested" is on the label

Every skill was graded against paired baseline runs — the same pressure
scenario executed with and without the skill. **12 of 13 discriminate
cleanly**: agents with the skill demonstrably behave differently than agents
without it. The thirteenth (`domain-glossary`) is documented honestly and
being hardened for the next release.

The eval scenarios ship inside the pack (`evals/evals.json` per skill), so you
can re-run the evidence yourself instead of taking our word for it.
